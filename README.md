# 🌾 Farmedia - Agricultural Monitoring & Intelligence Dashboard

**Developed by Sarp Systems**

Farmedia is an AI-powered Earth observation and agricultural decision support system designed to help farmers mitigate climate risks, optimize irrigation, and prevent crop loss using multi-layered NASA satellite telemetry.
